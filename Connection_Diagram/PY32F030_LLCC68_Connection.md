# PY32F030F28P6 与 LLCC68 引脚连接说明

当前原理图：U1 为 PY32F030F28P6TU（TSSOP20、Pinout2），U2 为 LLCC68（QFN24），U3 为 PE4259-63（SC-70-6，单控制模式），共用 3.3 V 电源。主控已接 X1（24 MHz）外部无源晶体，LLCC68 已接 X2（32 MHz）无源晶体；主控是否使用外部晶体还需由固件配置。

本文的“当前连接”按嘉立创工程 Schematic1 / P1 的已保存数据整理，本次复核读取至 **2026-10-15 22:48:11、ticket 33439**。最新原理图已填写大部分射频数值、新增 C26=100 pF，并将 L7 改为15 μH、0805通用器件；具体采购型号仍需绑定。此前核对过PCB网络数据，本次读取过程中也已见新增C26等PCB同步记录，但未完整复核最新PCB、运行原生ERC或验证实测性能。设计中心频率为 **490 MHz**；第 3 节列出采购型号及目标连接，第 6 节区分已落实和仍待修正的项目。

**2026-10-15 本次助手更新范围：仅更新本 MD，不修改嘉立创原理图或 PCB。** 元件位号按本工程，不能直接套用 Semtech 参考板的位号。射频元件保留英制0603（公制1608）；**L7最终选用15 μH、英制0805（公制2012）的TDK MLZ2012M150WT000，立创C383402，不再采用此前10 μH候选。**

**保留的设计要求：VREG 对地电容使用 470 nF，VBAT 配置 100 nF 与 10 μF 去耦。原理图目前 C5 为 100 nF，且尚无 VBAT 的 10 μF 电容，这两项应修改原理图，不将文档要求改成现有错误值。** 其余连接按实际记录；已知问题与待验证事项见第 6 节。

## 3. 射频开关与匹配网络

### 射频开关

当前原理图已选用 **U3：PE4259-63（SC-70-6），使用单控制模式**。DIO2 高电平选通发射支路、低电平选通接收支路；以下为工程实际接法。

以下按物理脚号列出 PE4259 的全部 6 脚。它没有另需连接的底部 EP。

| 脚号 | 引脚名称 | 连接到哪里 | 配置与作用 |
|---|---|---|---|
| 1 | RF1 | 接 LLCC68 第23脚 RFO 经发射匹配、滤波及所需隔直网络后的输出端 | TX 支路；CTRL 高时与第5脚 RFC 导通 |
| 2 | GND | 接公共 GND 平面，与 PY32 和 LLCC68 共地 | 地连接尽量短 |
| 3 | RF2 | 接由 LLCC68 第21脚 RFI_P、第22脚 RFI_N 构成的接收匹配、巴伦网络的单端接口，按网络要求隔直 | RX 支路；CTRL 低时与第5脚 RFC 导通 |
| 4 | CTRL | 经 R7=100 Ω 接 LLCC68 第12脚 DIO2；本脚经 C8=1 nF 接地 | 单控制输入；高选 TX、低选 RX |
| 5 | RFC | 当前经C26=100 pF、L1=15 nH接天线座RF1第4脚（SIG）；C7/C6各4.7 pF，分别从L1两端接地；RF1第1、2、3脚接地 | 收发公共端；C26已加入，位置正确，对应此前临时名称C_RF_DC，与C15是不同元件 |
| 6 | CTRL 或 VDD（单控制模式用作 VDD） | 接 3V3；C9=1 nF 接地 | 开关供电；须满足下文电压范围要求 |

| LLCC68 DIO2 / PE4259 CTRL | 开关导通路径 | 对应状态 |
|---|---|---|
| 高 | 第5脚 RFC ↔ 第1脚 RF1 | 发射支路接天线 |
| 低 | 第5脚 RFC ↔ 第3脚 RF2 | 接收支路接天线；不代表 LLCC68 一定处于接收模式 |

PE4259 推荐供电范围为 1.8–3.3 V。采用标称 3.3 V 电源时需核对容差和纹波，确保不超出工作范围。其射频端口需串联隔直电容或保持 0 V 直流电位；应结合整条匹配网络检查，避免遗漏或重复添加。若改用互补控制模式，须另行提供互补信号；若更换开关型号，须重新核对脚号和真值表。

### 490 MHz 目标连接及新增隔直电容的位置

以下为目标连接，并注明最新原理图的落实情况。为避免混淆，U3第1脚RF1是开关端口，元件RF1是天线连接器。

1. **功放馈电**：U2第24脚VR_PA经L2=82 nH接到U2第23脚RFO所在节点，即L3的芯片侧；C10=47 nF和C11=82 pF均从VR_PA接地。当前L2接在L3之后，后续按参考图移到L3之前。L3装0 Ω时，两侧在理想电路中等电位；此项主要是与原厂射频布局保持一致。
2. **发射支路**：U2第23脚RFO → L3位置的0 Ω → L4=8.2 nH → L5=15 nH → C15=100 pF → U3第1脚RF1。**当前L3标N.M.，若按此不装，会切断RFO到匹配网络的通路，同时使当前L2馈电无法到达RFO，必须改为装0 Ω。** 当前C15在L5之前，建议按参考图交换顺序；两者中间无其他支路时，理想集总电路串联次序等效，但实板寄生与布局不完全等效。C12=3.6 pF跨接L4；C13是L4输入侧对地预留位、不装；C14=12 pF从L4/L5连接点接地；C16=6.0 pF从C15之后、U3第1脚所在节点接地。
3. **接收支路**：L6=33 nH跨接U2第21脚RFI_P与第22脚RFI_N；C17=3.9 pF从RFI_P接地；RFI_N经C18=4.7 pF接U3第3脚RF2；C19=1.0 pF从U3第3脚所在节点接地。**C19保留在C18之后、开关侧；参考图的C7就在此处，不应移到RFI_N芯片侧。**
4. **天线公共支路（已落实）**：U3第5脚RFC与C7/L1输入节点之间已串联C26=100 pF；C7=4.7 pF、L1=15 nH、C6=4.7 pF组成其后的滤波网络，连接如下。

```text
U3 RFC（5脚）── C26（100 pF）────────●── L1（15 nH）──●── 天线座RF1第4脚SIG
                                     │                 │
                                 C7（4.7 pF）      C6（4.7 pF）
                                     │                 │
                                    GND               GND
```

C26的一端只接U3第5脚RFC，另一端接C7非接地端及L1输入端；本次已核对新增连接位置及两侧网络。电容两侧必须保持不同网络，不能保留绕过电容的导线或使用同名网络标签将其短接。天线座RF1第1、2、3脚继续接地。C26隔开开关公共端与天线侧的直流通路；**不替代C15，也不是在C15旁边再串第二颗电容。**

射频控制仍为DIO2经R7=100 Ω到U3第4脚、C8=1 nF接地；U3第6脚接3V3、C9=1 nF接地。PCB还需根据实际叠层落实50 Ω传输线、连续参考地和EP接地。490 MHz中心频率不代表已验证整个470～510 MHz频段的匹配及性能。

## 4. 外部接口与固件配置

### SWD 接口

当前下载座 CN1 为 WAFER-GH1.25-4PWB，四个信号脚如下：

| CN1 脚号 | 网络 | 板端连接 |
|---|---|---|
| 1 | 3V3 | 板上3.3 V电源，可按下载器定义连接 VTref |
| 2 | SWDIO | U1 第10脚 PA13 |
| 3 | SWCLK | U1 第11脚 PA14 |
| 4 | GND | 公共地 |

CN1 第5、6焊盘在工程中标为不连接。**当前 CN1 没有 NRST**；U1 第18脚仅接板上 PY32_RST 复位网络和 SW2。需要下载器控制复位时，应另接该网络或后续扩展接口。VTref 是目标电压参考，不能默认当作下载器供电输出；若由下载器给板子供电，需按下载器定义确认接线及供电能力。

### GPIO 引出与串口

| 接口 | 脚号 | 网络及去向 |
|---|---|---|
| CN2（WAFER-GH1.25-3PWB） | 1 | PB7 → U1 第14脚 |
| CN2 | 2 | PB6 → U1 第13脚 |
| CN2 | 3 | PA12 → U1 第8脚 |
| CN3（WAFER-GH1.25-2PWB） | 1 | PY32_RX → U1 第2脚 PA3；外接设备 TX |
| CN3 | 2 | PY32_TX → U1 第1脚 PA2；外接设备 RX |

CN2 第4、5焊盘和 CN3 第3、4焊盘在工程中标为不连接。CN2、CN3 均未引出 GND；使用外部设备时需通过其他连接与本板共地，不能把未连接的焊盘当作地线。

### 固件必须配合的设置

- 若使用已接入的 X1，应按24 MHz外部晶体配置主控 HSE 及后续时钟树；本文不代表固件已经完成时钟配置。CN2 上的 GPIO 按实际外接功能配置，不能一律当作未连接引脚。
- SPI 使用 Mode 0（CPOL=0、CPHA=0）；PA4 作为软件片选，空闲保持高电平。
- 按 LLCC68 的 BUSY 握手时序发送命令；常规命令发送前等待 BUSY 为低，休眠唤醒按手册规定的 NSS/BUSY 流程处理。
- 硬件采用本表 DC-DC 外围时，在 STDBY_RC 模式下调用 `SetRegulatorMode(0x01)`。芯片复位后默认使用 LDO，仅安装电感不会自动启用 DC-DC。
- 调用 `SetDIO2AsRfSwitchCtrl(0x01)` 启用射频开关控制，DIO2 不再作为普通 IRQ 输出。
- 通过 `SetDioIrqParams` 将所需的 TxDone、RxDone、Timeout 等事件映射到 DIO1，并设置相应 IRQ 掩码；处理中断时读取状态，处理后清除相应 IRQ 标志。
- 使用本表的无源晶体方案时，不调用 `SetDIO3AsTCXOCtrl`。LLCC68 内置可调晶体负载电容，不应未经计算就额外添加固定外部负载电容；根据晶体 CL、寄生电容和频偏确定配置。若需修改 XTA/XTB 电容寄存器，应在 STDBY_XOSC 模式下进行。
- 保留 PF2 的 NRST 功能、PA13/PA14 的 SWD 功能；启动选项字节与 BOOT0 下拉方案保持一致。

以上为配置要点，不代替完整的无线芯片初始化及收发流程。

## 5. VDD_IN 滤波支路核对结论

当前原理图U2第1脚直接接3V3，与第10、11脚同网，未串联47 nH电感；本次已用所选490 MHz原厂参考设计核对此问题。

本地 `DS_LLCC68.pdf`（Rev. 1.0，July 2019）存在以下信息差异：

- 第 29 页 §5.1 的文字提到 VDD_IN（1脚）前的 **47 nH 电感**，并说明仅使用 LDO 时可省去该电感及 7、9 脚之间的 15 μH 电感。
- 第 96 页图 14-1 的应用示意图未画出 VDD_IN 前的 47 nH 电感，且该页要求以最新原厂参考设计为准。

已核对E570V01A参考图：U1第1脚VDD_IN直接接VDD_RADIO，配C16=1 μF对地，未在此脚前单独串47 nH；其L7仍为DC-DC外围电感。因此，本项目按该490 MHz参考设计执行，**不把缺少47 nH判为接线错误，也不额外要求补装；需要补齐的是VDD_IN贴脚1 μF去耦。** 参考板还设有上游供电及去耦网络，不能据此省略本板电源完整性检查。
