| PY32F030F28P6（TSSOP20）引脚 | 连接方式 | 作用 |
|---|---|---|
| PA5（4脚） | 接 LLCC68 SCK（18脚）；配置 SPI1_SCK、AF0 | SPI 时钟 |
| PA7（6脚） | 接 LLCC68 MOSI（17脚）；配置 SPI1_MOSI、AF0 | 主控向无线芯片发送数据 |
| PA6（5脚） | 接 LLCC68 MISO（16脚）；配置 SPI1_MISO、AF0 | 主控读取无线芯片数据 |
| PA4（3脚） | 接 LLCC68 NSS（19脚）；10 kΩ 上拉至 3.3 V；配置 GPIO 输出 | SPI 片选，低有效 |
| PA0（19脚） | 接 LLCC68 BUSY（14脚）；配置 GPIO 输入 | 检测无线芯片忙状态，高表示忙 |
| PA1（20脚） | 接 LLCC68 DIO1（13脚）；配置 EXTI1 上升沿中断 | 接收发送完成、接收完成等中断通知 |
| PB5（12脚） | 接 LLCC68 NRESET（15脚）；10 kΩ 上拉至 3.3 V；配置 GPIO 输出 | 控制无线芯片复位，低有效 |
| PA2（1脚） | 接外部设备 RX；配置 USART1_TX、AF1 | 3.3 V 串口发送 |
| PA3（2脚） | 接外部设备 TX；配置 USART1_RX、AF1 | 3.3 V 串口接收 |
| PA13（10脚） | 接下载器 SWDIO | 程序下载与调试数据 |
| PA14（11脚） | 接下载器 SWCLK | 程序下载与调试时钟 |
| PF2-NRST（18脚） | 接下载器 NRST；10 kΩ 上拉至 3.3 V；100 nF 对地；复位按键接地 | 主控复位，保留 NRST 功能 |
| PF4-BOOT0（15脚） | 10 kΩ 下拉至 GND；配合启动选项字节配置 | 选择主 Flash 启动 |
| VCC（9脚） | 接 3.3 V；100 nF 与 1 μF 电容分别接至 GND | 主控供电与去耦 |
| VSS（7脚） | 接 GND，与 LLCC68、外部串口设备及下载器共地 | 公共参考地 |
| PA12（8脚） | 不连接，配置为模拟输入 | 预留 GPIO |
| PB6（13脚） | 不连接，配置为模拟输入 | 预留 GPIO |
| PB7（14脚） | 不连接，配置为模拟输入 | 预留 GPIO |
| PF0（16脚）、PF1（17脚） | 使用主控内部时钟时不连接 | 外部晶体接口预留 |

| LLCC68（QFN24）外围引脚 | 连接方式 | 作用 |
|---|---|---|
| VDD_IN（1脚） | 接 3.3 V，与 VBAT 同网；1 μF 电容接至 GND | 内部功放稳压器供电输入 |
| VBAT（10脚） | 接 3.3 V；100 nF 与 10 μF 电容分别接至 GND | 无线芯片供电与发射瞬态去耦 |
| VBAT_IO（11脚） | 接 3.3 V；100 nF 电容接至 GND | 数字接口供电 |
| GND（2、5、8、20脚）及 EP | 全部接地；EP 焊接至地平面并布置地过孔 | 接地与散热；EP 在手册中为0号，部分封装库标25号 |
| DCC_SW（9脚） | 经 15 μH 电感接 VREG（7脚）；采用原厂 DC-DC 外围方案 | 内部 DC-DC 开关输出 |
| VREG（7脚） | 470 nF 电容接至 GND；不得直连 3.3 V | 内部稳压输出及滤波 |
| VR_PA（24脚） | 接功放去耦和射频扼流网络；器件值按目标频段参考设计确定；不得直连 3.3 V | 为内部射频功放提供受控电源 |
| XTA（3脚） | 接 32 MHz 晶体一端；负载电容按晶体 CL 与芯片内部电容配置确定 | 射频参考时钟 |
| XTB（4脚） | 接同一 32 MHz 晶体另一端；晶体外壳地脚按其手册接地 | 射频参考时钟 |
| DIO3（6脚） | 本晶体方案不连接，不启用 TCXO 供电功能 | TCXO 控制接口预留 |
| DIO2（12脚） | 接射频开关控制网络；按开关真值表连接，启用 DIO2 射频开关控制 | 发射时高电平，其他状态低电平，用于收发切换 |
| RFO（23脚） | 经发射匹配、滤波网络接射频开关 TX 端；L/C 值按频段确定 | 射频发送输出 |
| RFI_P（21脚） | 与 RFI_N 配合，经接收匹配、巴伦网络接射频开关 RX 端 | 差分射频接收正端 |
| RFI_N（22脚） | 与 RFI_P 配合接收匹配网络，不直接与 RFI_P 短接 | 差分射频接收负端 |
| 射频开关公共端 | 经天线匹配网络接 50 Ω 天线接口 | 共用收发天线 |
